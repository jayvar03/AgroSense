# AgroSense Modern React Frontend

Clean, responsive, farmer-first frontend built with **Vite + React (JavaScript / JSX) + Tailwind CSS**.

---

## Features
- **Modern Bento UI**: Clean dashboard layout with emerald agricultural accents.
- **Crop Advisor**: Input soil N-P-K & pH with 1-click GPS weather detection via Open-Meteo.
- **Leaf Disease Scanner**: Drag & drop leaf photo diagnosis with Gemini AI and instant PDF download.
- **Soil Health Advisor**: Find replenishing rotation crops, organic matter, and fertilizer recipes.
- **History & Profile**: Past prediction timeline with search filters and profile editing.

---

## Quick Setup

### 1. Install Dependencies
```bash
cd new/frontend
npm install
```

### 2. Configure Environment
Check `.env`:
```env
VITE_API_URL=http://localhost:5000
```

### 3. Run Development Server
```bash
npm run dev
```

The frontend will run at `http://localhost:5173`.
